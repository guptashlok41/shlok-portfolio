SHLOK GUPTA — DEVELOPER PORTFOLIO

Before publishing:
1. Replace each project GitHub profile link with the direct repository URL.
2. Add your professional email and LinkedIn URL in the contact section.
3. Verify the project descriptions, skills, metrics and graduation details.
4. Optionally add a resume PDF link.

Deploy with GitHub Pages:
1. Create a public repository named shlok-portfolio.
2. Upload index.html, style.css and script.js to the repository root.
3. Open Settings -> Pages.
4. Select Deploy from a branch, branch main, folder /(root), then Save.
5. Your site will appear at https://YOUR_USERNAME.github.io/shlok-portfolio/ after deployment.

Static website; no build step required.
